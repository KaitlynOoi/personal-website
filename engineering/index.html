002

LTspice → QSpice Conversion Tool

A CLI + GUI tool that converts LTspice .asc schematics into QSpice-compatible .qsch files, then patches every known LTspice/QSpice incompatibility so the result actually simulates. Verified against real production circuits.

  • Resolves each component to its real QSpice-drawable symbol
  • Fixes logic gates, switches, coupled inductors, missing models
  • Verified on a CLLC resonant converter and a CV+CC control loop
  • Packaged as a standalone .exe with PyInstaller

Flighttrack

A self-hosted flight price monitor, deployed to a VPS and shared with friends. Runs a background scraper on a schedule, then alerts through a Telegram bot and a remote MCP server so anyone can ask Claude about their tracked flights.

  • Telegram bot: /track, /list, /stop, instant price-drop alerts
  • Remote MCP server (Streamable HTTP) with per-user scoped tokens
  • Scheduler + scraper + bot all sharing one Postgres database
  • Deployed on a persistent VPS, not free-tier serverless
